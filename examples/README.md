# Examples

Examples are historical executable design fixtures, not the default current workflow.

The older examples below preserve the full v1 chain for compatibility. New v2 tasks follow only their requested output set, reuse authorization and return usable work without mandatory stage confirmations. Current behavior is tested with raw requests in `tests/fixtures/content-first/cases.json`.

The historical chain was:

```text
idea intake
-> director room notes
-> concept options
-> selected concept
-> outline
-> treatment
-> script
-> script breakdown
-> shot list
-> visual bible
-> co-creation gates
-> image prompt manifest
-> video prompt manifest
-> QA report
```

Current fixtures:

- `cyber-courier`: cinematic 15s narrative test.
- `product-ad-raincoat`: product advertising and 180s longform capability test.
- `zombie-cleaner-test`: public-reference-inspired 180s genre short E2E test in prompt-only mode.
- `live-user-sim-noodle`: 15s product ad UX simulation with visible user choice gates and prompt-only export.
