## Reuse Boundary

This fixture does not recreate the referenced film.

It uses only high-level benchmark traits:

- compact AI short format,
- zombie wasteland comedy,
- single hero with a strange vehicle,
- strong visual contrast,
- model-safe longform packaging,
- Seedance-friendly multi-reference planning.

Original test concept:

`Wasteland Sanitation Route`: a municipal cleanup worker drives a jury-rigged street sweeper across a zombie quarantine belt to collect one glowing waste barrel before dawn.

## Test Purpose

Stress DIRcreative on:

- 180s longform decomposition,
- genre clarity,
- black-comedy tone without copying,
- character/vehicle/zombie consistency,
- dense boards versus clean frame routing,
- prompt-only mode,
- model-specific video prompt export.
