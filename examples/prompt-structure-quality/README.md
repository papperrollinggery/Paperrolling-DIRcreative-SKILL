# Scene-led prompt examples

Six Chinese T2V authoring examples exercised from an isolated installed method,
then reviewed for source fidelity and causal gaps. They are authored prose,
not compiler golden files, reference images or generated videos. No attachments
or executed model parameters are claimed.

| File | Different requirement it preserves |
| --- | --- |
| action-chase.txt | two distinct subjects, connected physical escape, ending in motion |
| environment-reveal.txt | unoccupied place as subject; the umbrella exists before light reveals it |
| kinetic-type.txt | exact Chinese text, flat black/white/red design and readable end pulse |
| quiet-dialogue.txt | exact dialogue, object-triggered listening and an intentional quiet ending |
| product-turn.txt | quarter-turn geometry, material response and a requested static final second |
| character-pv.txt | one stylized character, prop release/catch, graphic transitions and no invented fight |

The maintained method is `skills/dircreative/references/prompt-structure.md`.
Read the scene and constraints before adapting; do not treat these prompts as
fixed duration/shot-count/negative-list recipes. Full source study:
`docs/film-preproduction/research/prompt-structure-20260909.md`.

These examples demonstrate text authoring and review only. Model-native video,
identity, exact glyphs, physical timing and audiovisual quality remain unverified
until actual candidate clips and their submission evidence are inspected.
