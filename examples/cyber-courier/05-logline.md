## Primary Logline

In a neon rainstorm, a disciplined courier enters a forbidden alley to deliver a sealed package, then realizes the destination is not a person or address, but a dormant machine that wakes only when the package arrives.

## Compact Logline

A rain-soaked cyber courier delivers a sealed package to a forbidden alley and triggers the alley itself to wake up.

## Story Engine

```yaml
protagonist: young adult courier in a red waterproof jacket
visible_goal: deliver the black confidential package to the alley endpoint
inner_pressure: professional duty fighting survival instinct
obstacle: the alley is known as a place nobody enters, and it appears to react to the package
stakes: if he turns back, he fails a delivery tied to a hidden network; if he continues, he activates something unknown
turn: the package seal begins glowing before anyone receives it
ending_type: suspense hook
final_image: metal door and intercom lighting up as the courier freezes in the rain
```

## Theme Statement

Professional duty can pull a person across the boundary between ordinary systems and hidden ones.

## Visual Promise

The short should read without dialogue: a red figure, black package, blue-black rain, red scanner glow, and one final mechanical response from the forbidden alley.
