# Audio Design Notes

Verified: 2026-05-14

Purpose: prevent the system from confusing image prompts, video prompts, production sound plans, and post-production audio.

## Core Rule

Image prompts do not generate sound.

Image references may include audio planning labels for humans and downstream adapters, but the video prompt must explicitly restate sound requirements.

## Audio Decision Tree

```text
Does the deliverable require sound?
-> no: mark silent visual-only.
-> yes: is the target model audio-capable in this workflow?
   -> no: write post-production audio plan only.
   -> yes: decide dialogue / VO / SFX / ambience / music / silence.
```

## Required Audio Questions

- Is this sound-on or sound-off first?
- Does the clip need dialogue?
- If yes, is the speaker visible or off-screen?
- Does it need voiceover instead of lip-synced dialogue?
- Does the scene need ambience?
- Does it need discrete sound effects?
- Does it need music?
- Is music diegetic or non-diegetic?
- Is intentional silence part of the creative effect?
- Should audio be generated by the video model or handled in post?

## Channel Defaults

| Channel | Default audio strategy |
| --- | --- |
| Film short | Ambience and silence first; dialogue only when it changes story. |
| Commercial | VO/BGM/SFX often required; CTA must be explicit if present. |
| Short drama | Dialogue/reaction timing first; music supports tension but must not obscure speech. |
| Short video | Sound hook and captions are separate requirements; make silent-safe variant. |
| MV | Music is the spine; video timing should map to music sections. |

## Prompt Placement

### Image prompt

Use only production labels:

```text
Include a small Audio Plan box listing: rain ambience, distant electrical buzz, no dialogue, no music.
This is a planning label only.
```

### Video prompt with audio

Use explicit audio section:

```text
Audio: steady rain ambience, distant neon electrical buzz, soft package scanner beep at 00:07, no dialogue, no music.
```

### Video prompt without audio

Use explicit silent instruction:

```text
Audio: silent visual-only clip, no dialogue, no music, no sound effects.
```

### Post-production audio plan

Use if target model does not support reliable audio:

```yaml
audio_policy:
  generation_mode: post_production
  ambience: rain and distant traffic
  sfx:
    - package scanner beep at shot 3
    - wet footsteps under shots 1-5
  music: low pulsing noir synth begins after shot 2
  dialogue: none
```

## Dialogue Rules

- Visible dialogue requires speaker, language, exact line, emotion, and timing.
- For AI video models, short lines are safer than long lines.
- Voiceover is safer than lip sync when exact mouth movement is not critical.
- If using subtitles, plan them as separate overlay/post-production assets unless the image/video model is explicitly asked to render readable text and verified.

## SFX Rules

- SFX must attach to visible or implied events.
- Do not add decorative SFX without story function.
- Important prop sounds should appear in the shot list and audio plan.

## Music Rules

- Music should not be buried inside style words.
- Specify mood, instrumentation, tempo, and entry/exit if needed.
- Ads and short videos may need a clear sonic hook.
- MV workflows must start from music map before shot design.

## Silence Rules

Silence is not absence of planning. It is a creative decision.

Use silence when:

- tension matters more than information,
- the model's audio would distract,
- post-production audio is planned,
- reference image/video generation is only for visual previs.

## Common Failures

- Writing music into image prompts and expecting it to affect video.
- Assuming the video model will read tiny storyboard labels.
- Asking for dialogue without specifying exact speaker and line.
- Combining loud music, dialogue, and SFX in a 5-second clip.
- Forgetting silent/caption-safe versions for short video.
